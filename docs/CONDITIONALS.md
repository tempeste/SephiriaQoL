# Sephiria layout-condition audit

Validated against Sephiria 1.0.27. This inventory is based on runtime types and
behavior, not translated tooltip wording alone.

## Reusable activation criteria

`Charm_Basic.criteria` has ten concrete criteria. Nine depend on layout:

- artifacts on both horizontal sides
- both horizontal sides empty
- bottom six inventory slots
- inner slots
- an adjacent Grimoire in any of the eight neighboring slots
- all eight neighboring slots occupied
- outermost slots
- either end column
- top row

The tenth criterion is full HP and is not positional. The native inventory refresh
evaluates these criteria for every candidate generated by the auto-arranger, so the
QoL plugin does not duplicate them. `CharmActivateCriteria_CnadyThreeWay` exists as
a localization key but has no concrete runtime class in this game version.

## Artifact-specific positional behavior

The runtime contains thirteen additional positional behaviors:

| Runtime type | Layout dependency | Optimizer treatment |
| --- | --- | --- |
| `Charm_UpCharmDamage` | Configured offset, normally the artifact above; Needle chains are allowed | Scores a chain only when it ends at a direct-damage artifact |
| `Charm_RightSpellCooldownHelper` | Grimoire immediately right | Scores configured cooldown recovery |
| `Charm_ReduceMPCost` | Grimoire immediately left | Scores configured MP reduction |
| `Charm_AutoMagic` | Bolt Grimoire immediately below | Scores the valid auto-cast link and its interval |
| `Charm_NearLevelDamage` | All eight neighboring slots | Scores capped neighboring levels and the final-damage coefficient |
| `Charm_NearMagicBullet` | Every Grimoire sharing the same X coordinate | Scores Grimoire count and firework damage; the English tooltip says “row,” but the runtime searches a column |
| `Charm_PlanetModule` | Planet artifacts in the eight neighboring slots | Scores each uniquely enhanced Planet's 50% damage increase |
| `Charm_CompanionChaos` | Companions sharing the same Y coordinate | Rewards unique same-row companion links |
| `Charm_WhitePaper` | Left and right artifacts share a category | Rewards a valid shared-category pair |
| `Charm_WoodenBox` | Artifact count in the first/top six slots | Scores its three elemental-damage bonuses |
| `Charm_3Elemental_ByRow` | Inventory row selects the granted combo/element | Neutral: the best element depends on the build |
| `Charm_FireIce` | Left/right half changes which element is positive | Neutral: the best side depends on the build |
| `Charm_FireIceWeapon` | Left/right half selects Fire/Ice conversion | Neutral: the best side depends on equipped effects |

Inventory-wide effects such as Bolt Multi-Shot and cooldown-by-magic-tag are real
conditionals, but rearrangement cannot change which artifacts they affect, so they
need no positional score.

## Tablets

Stone Tablets have a separate query system supporting fixed slots, directional
lines, rows/columns, diagonals, edges, checkerboards, knight offsets, and item-type
criteria. Sephiria's native candidate evaluator parses those queries, applies tablet
levels/conditions, refreshes artifact activation, and produces the base optimizer
score. Keep that native path authoritative; `ConditionalSynergyScoring` should add
only artifact effects that the base level score cannot measure.
